## 작업 방식

제출물이 노트북 하나라 데이터 처리, vocab, 모델 저장 형식을 통일하기 위해 공통 베이스라인을 먼저 만들고, 번역 방향을 한 명씩 맡아 학습과 기능 구현을 진행함. 각자 브랜치에서 작업 후 PR로 merge.

## 담당

| 담당 | 방향 | 직접 구현 |
| --- | --- | --- |
| 박정연 | 베이스라인, 통합, 제출 | - |
| 김태우 | num2en | Bahdanau attention |
| 김한나 | en2num | 양방향 encoder |
| 홍정표 | num2ko | beam search 길이 패널티 |
| 김서현 | ko2num | 짧은 숫자 오버샘플링 |
| 김수현 | en2ko | en-ko 데이터 증강 |
| 이재노 | ko2en | 입력 정규화 함수 |

## 작업 방법

1. Colab에서 `project01/work/baseline.ipynb`를 열어 `<방향>.ipynb`로 사본 저장
2. Colab 사용 시 셀의 git clone, %cd 주석 해제 후 설정 셀에서 SRC, TGT 변경
3. 담당 기능 구현 후 GPU로 전체 실행, 기본 버전과 비교 결과를 노트북에 기록
4. 노트북(실행 결과 포함)은 `project01/work/`, `.pt`는 `project01/`에 업로드
5. 커밋할 때 새 브랜치(방향 이름)를 만들고 PR 생성, PR 설명에 구현 내용과 test 정확도 기록
